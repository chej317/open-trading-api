# 삼성전자 자동매매 프로그램 (모의투자용)

이 프로그램은 한국투자증권 KIS Open API를 사용하여 삼성전자(005930)를 자동으로 매매하는 시스템입니다.

## 주요 기능
- **폴링 방식:** REST API를 주기적으로 호출하여 현재가 및 잔고 확인.
- **매매 로직:** 현재가 기준 -2,000원에 매수, +2,000원에 매도 주문 전송.
- **안전성:** 모의투자 API 제한을 고려한 지연(0.5초) 및 토큰 캐싱 기능 포함.
- **운영 시간:** 평일 09:10 ~ 15:30 사이에만 동작.

## 설치 및 설정

1. **필요 라이브러리 설치:**
   ```bash
   pip install -r requirements.txt
   ```

2. **환경 변수 설정:**
   `.env` 파일을 생성하거나 시스템 환경 변수에 아래 항목을 설정하세요.
   - `GH_APPKEY`: KIS API 앱키
   - `GH_APPSECRET`: KIS API 앱시크리트
   - `GH_ACCOUNT`: KIS 종합계좌번호 (8자리)

## 실행 방법
```bash
python -m samsung_auto_trader.main
```

## 주의 사항
- 이 프로그램은 **모의투자(Mock Trading)** 전용으로 설계되었습니다.
- 실전 투자에 사용할 경우 TR ID 및 URL 변경이 필요하며, 충분한 검증이 필요합니다.
- API 호출 횟수 제한으로 인해 너무 짧은 폴링 간격은 피하시기 바랍니다.
